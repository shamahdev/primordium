# Primordium

Primordium helps Valorant players browse live store offers and public cosmetic reference data for their saved Riot accounts.

## Language

**Cosmetic Catalog**:
The public reference set of Valorant cosmetics shown for browsing, independent of whether a player owns the items or can currently buy them.
_Avoid_: Collection, inventory

**Favorite**:
A device-local marker a player applies to a Cosmetic Catalog item for quick access inside Primordium.
_Avoid_: Wishlist, bookmark

**Favorite Store Alert**:
A device-local notification that tells a player when one or more Favorites appear in the active Stored Riot Account's daily or accessory Store offers.
_Avoid_: Wishlist alert, exact reset alert
